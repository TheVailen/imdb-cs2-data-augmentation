# Обогащение данных на примере IMDb и CS2

Курсовая работа по дисциплине «Фреймворки для анализа данных».

В работе сравниваем, как добавление новых реальных и синтетических примеров влияет на качество моделей и разброс результатов между запусками. Для сравнения взяли две задачи: определение тональности отзывов о фильмах и обнаружение персонажей на кадрах из CS2.

## Датасеты

| Датасет | Задача |
|---|---|
| [IMDb Dataset of 50K Movie Reviews](https://www.kaggle.com/datasets/lakshmi25npathi/imdb-dataset-of-50k-movie-reviews) | Определить, положительный отзыв или отрицательный. |
| [CS2 Object Detection](https://universe.roboflow.com/nikimauzer-rscbx/cs2-shsmv) | Найти персонажей на кадре, обвести их рамками и определить команду (`T` или `Counter terrorist`). |
